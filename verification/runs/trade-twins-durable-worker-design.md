## Freeze and original ownership

Accept only original parent job identity and strict selected configuration ordinal. Inherit its current verified configuration, costs, account, data/context/action/news/borrow identities and seed. Both declared policies and10000 sets are mandatory; requests cannot amend quantities, assumptions, count, seed or policy after seeing results. Legacy/final/shared-portfolio/control sources are not silently converted into discovery-version parents.

Create one original child reservation per parent account ordinal and protocol version, using an atomic original journal and unique constraint. A concurrent/repeated request returns the existing linked child. Missing/corrupt linked children, input records or original events refuse replacement. Verify the original binding inside the reservation transaction after the initial original reader; never trust a caller's `verified` flag. A changed engine requires a new explicitly identified parent account, not amended historical traces or rehashed old financial artifacts.

Queue preparation asynchronously. Freeze source identity, original cohort and prospective symbol/date/warm-up scope before candidate prices. Check protected dates before each underlying read. Load only original data/actions, without regenerating signals or the parent account. Use the tested setup-chart, completed-as-of, split-normalized ATR definition. Seal/hash the entire outcome-blind matching plan and record its original commit before any candidate P&L. Empty/zero-duration/unmatched cohorts produce an explicit whole-comparison ineligible result, with zero executed financial sets and no fabricated completed trial rows.

## Original financial books and bounded work

A reusable one-trade book key binds the original authority and matching-plan hashes, entire selected match, configuration, costs, original quantity, data/actions/news/borrow identities, clock, numerical source and interpretation. It never includes observed profit as an input to eligibility or assignment. Commit the complete canonical Decimal book and its original hash/event before reuse. Recheck exact inputs and bytes on every lookup. A derived SQLite view is an index, never replacement authority.

Declare deterministic original part/set ranges before work. Choose a bounded stream representation that preserves every one of10000 ordinals under both policies and every original trade in each set. Do not hold the full outcome matrix in memory. Whole sets cannot be dropped or resized to meet a memory bound; stream their member references, then commit a set only after the complete cohort is present. Original trial/attempt rows must distinguish financial set occurrences from strategy configurations and from reusable one-trade computations. They must not inflate a search's effective independent-strategy assumption by10000 Monte Carlo draws.

The naive probe's10003 full authority reads took most of its1009-second wall time. A bounded original part can be the work unit: verify full original authority before its first new/reused outcome and again before its commit/publication; keep prepared inputs immutable during the part; verify each financial book's original input/byte identity on reuse. Never publish a part whose closing authority check fails. Prove this boundary with source/price/action/news/borrow/guard/parent mutations during work and before commit. Timing evidence alone does not justify removing a guard or accepting a stale worker. Check cancellation and source freshness at bounded member checkpoints too.

Persist original attempts, computation-start records, checkpoint files and events with ordering fences, using existing journal/lease conventions. Preserve orphaned files rather than deleting failed work. Resume the original owned child/part attempt, verify previously committed originals before reuse, and refuse unexpected parts, duplicates, missing rows, swapped policies, gaps, contradictory sidecars or superseded attempts. A killed worker must not leave a second worker able to commit the same job. No user taskkill should be needed.

## Financial failures and exact grading

Unfillable original quantity or unavailable borrowing is an original failed candidate. Exact-duration recall failure retains its actual mandatory liquidation. Nonpositive modeled quotes and arithmetic/data failures retain the original failed computation/attempt and useful safe diagnostics; they cannot disappear through a new draw. Each set retains all original assignments. Any failed member makes that policy's set failed, with no invented net profit. Source corruption/protected-date failure stops further computation and prevents publication.

Use canonical Decimal money end to end. Adopt the tested exponent-span-safe total for original source closed profit and set aggregation. Preserve the marked-account reconciliation residual and exact baseline used. The existing legacy float grading interface stays separate; the flat integration probe's lossless zero conversion does not authorize float conversion for arbitrary books. Count ties against the source, require exactly10000 complete ordinal-unique full-cohort sets, retain499/500 strictness, and keep raw fraction, plus-one diagnostic and conditional exact95% interval distinct. A failed or incomplete denominator has no passing score.

Publish a small original root summary only after verifying all original plan/part/trial/attempt/book occurrences and the final original source binding. No completed subset can stand in for a full comparison. The primary barrier-capped policy and exact-duration sensitivity remain labeled; users cannot select the favorable policy retrospectively.
